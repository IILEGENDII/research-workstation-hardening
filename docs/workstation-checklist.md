# Preparing a research workstation

1. Confirm data ownership, confidentiality and transfer authorization before moving university research data. Keep all development and initial checks on disposable synthetic material.
2. Review OS updates, local accounts, administrative access, disk encryption, independent recovery materials, firewall rules and endpoint protection using the platform's official instructions.
3. Select a configuration policy for the actual OS scope. Collect only with owner permission, investigate unknowns and preserve snapshots privately. A WSL or VM result covers only the guest environment.
4. Inventory dependencies with Project 5, review research code with Project 1, then establish signed data baselines with Project 2. Protect the baseline key independently.
5. Maintain independent backups, including offline or immutable copies where appropriate. Use Project 3 for recovery evidence. Disk encryption cannot replace backups.
6. Use Project 6 for the formats it actually supports. Keep this auditor's report separately pending a tested integration. Consider authenticated subject binding and independent evidence retention if needed.
7. Repeat after OS or policy changes. Track manual checks for patches, accounts, firewall rules, Linux storage encryption and Secure Boot alongside the scoped assessment.
